### Task 1: Add Limits tab to status-popover.tsx
**Type:** code
**Files:** `packages/app/src/components/status-popover.tsx` — EDIT

**Changes:**

1. Add rate limit data memo near other memos (after `pluginCount` line ~192):
   ```ts
   const limits = createMemo(() => Object.entries(sync.data.ratelimit ?? {}))
   const limitsCount = createMemo(() => limits().length)
   ```

2. Add `<Tabs.Trigger>` for Limits tab (after the plugins trigger, before `</Tabs.List>`):
   ```tsx
   <Tabs.Trigger value="limits" data-slot="tab" class="text-12-regular">
     {limitsCount() > 0 ? `${limitsCount()} ` : ""}
     {language.t("status.popover.tab.limits")}
   </Tabs.Trigger>
   ```

3. Add `<Tabs.Content value="limits">` (after the plugins content, before `</Tabs>`):
   ```tsx
   <Tabs.Content value="limits">
     <div class="flex flex-col px-2 pb-2">
       <div class="flex flex-col p-3 bg-background-base rounded-sm min-h-14">
         <Show
           when={limitsCount() > 0}
           fallback={
             <div class="text-14-regular text-text-base text-center my-auto">
               {language.t("status.popover.limits.empty")}
             </div>
           }
         >
           <For each={limits()}>
             {([id, info]) => (
               <div class="flex flex-col gap-2 w-full px-2 py-1.5">
                 <span class="text-12-regular text-text-weak uppercase tracking-wide">{id}</span>
                 <Show when={info.requests}>
                   {(req) => (
                     <div class="flex flex-col gap-1">
                       <div class="flex items-center justify-between">
                         <span class="text-12-regular text-text-base">
                           {language.t("status.popover.limits.requests")}
                         </span>
                         <span class="text-12-regular text-text-weak">
                           {req().remaining}/{req().limit}
                         </span>
                       </div>
                       <div class="h-1.5 w-full bg-surface-raised-base rounded-full overflow-hidden">
                         <div
                           class="h-full bg-icon-success-base rounded-full transition-all"
                           style={{
                             width: `${req().limit > 0 ? (req().remaining / req().limit) * 100 : 0}%`,
                           }}
                         />
                       </div>
                     </div>
                   )}
                 </Show>
                 <Show when={info.tokens}>
                   {(tok) => (
                     <div class="flex flex-col gap-1">
                       <div class="flex items-center justify-between">
                         <span class="text-12-regular text-text-base">
                           {language.t("status.popover.limits.tokens")}
                         </span>
                         <span class="text-12-regular text-text-weak">
                           {tok().remaining.toLocaleString()}/{tok().limit.toLocaleString()}
                         </span>
                       </div>
                       <div class="h-1.5 w-full bg-surface-raised-base rounded-full overflow-hidden">
                         <div
                           class="h-full bg-icon-success-base rounded-full transition-all"
                           style={{
                             width: `${tok().limit > 0 ? (tok().remaining / tok().limit) * 100 : 0}%`,
                           }}
                         />
                       </div>
                     </div>
                   )}
                 </Show>
               </div>
             )}
           </For>
         </Show>
       </div>
     </div>
   </Tabs.Content>
   ```

**Key design decisions:**
- Progress bar shows GREEN fill for **remaining** capacity (full = lots remaining, empty = depleted)
- `bg-icon-success-base` for the fill color (matches existing status indicator style)
- `bg-surface-raised-base` for the track (matches existing empty states)
- Numbers formatted with `toLocaleString()` for readability (100,000 not 100000)
- Provider ID shown as uppercase label above its limits
