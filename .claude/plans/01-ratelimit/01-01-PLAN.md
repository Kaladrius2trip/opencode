**Implementation details:**

**Schema shape (zod):**
```ts
const Dimension = z.object({
  limit: z.number(),
  remaining: z.number(),
  reset: z.string().optional(), // ISO 8601
})

const Info = z.object({
  providerID: z.string(),
  requests: Dimension.optional(),
  tokens: Dimension.optional(),
  input: z.number().optional(),  // input tokens remaining
  output: z.number().optional(), // output tokens remaining
  time: z.number(), // Date.now() timestamp of capture
}).meta({ ref: "RateLimit" })
```

**BusEvent:**
```ts
const Event = {
  Updated: BusEvent.define("ratelimit.updated", Info),
}
```

**State:**
```ts
const state = Instance.state(() => {
  const data: Record<string, Info> = {} // keyed by providerID
  return data
})
```

**parse function:** Takes `providerID: string` and `headers: Record<string, string>`. For `anthropic` provider, extracts `anthropic-ratelimit-*` headers. Returns `Info | undefined`.

**update function:** Calls `parse()`, if result exists, stores in `state()` and calls `Bus.publish(Event.Updated, info)`. Returns the parsed info or undefined.

**get/list functions:** Read from state.

**Key rules:**
- Use `parseInt(value, 10)` for numeric headers
- Guard with `if (!header) return undefined` early returns
- Only parse for recognized providers (Anthropic first, extensible later)
- The `parse` function must be pure (no side effects) for testability
- The `update` function handles storage + bus publishing
